## [0.0.1] - 2025-05-01
### Added
- Initial release of the Windsurf Linear Extension.
- Added commands accessible via Command Palette:
    - `Linear: Fetch My Teams`
    - `Linear: Fetch My Issues`
    - `Linear: Create Issue`
    - `Linear: Update Issue`
    - `Linear: Archive Issue`
- Configuration via VS Code settings (`windsurf-linear-extension.apiKey`).
- Utilizes `windsurf-linear` library for API calls.
- Added MIT License.
- Added extension icon.
