# Windsurf Linear Extension

This extension integrates basic Linear workflows into the VS Code editor environment.

## Features

*   Connects to your Linear account.
*   Provides commands to interact with Linear (e.g., fetch teams).

## Requirements

*   A Linear API key stored in a `.env` file in the extension's root directory (`LINEAR_API_KEY=your_key`).

## Usage

Use the Command Palette (`Cmd+Shift+P` or `Ctrl+Shift+P`) to access commands like:
*   `Linear: Fetch My Teams`
